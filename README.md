# Harmonica-Key web installer

Install page for Harmonica-Key (munspel-tonart) on the Waveshare ESP32-S3-Knob-Touch-LCD-1.8.

**Install:** open https://themidithief.github.io/harmonica-key/ in Chrome or Edge on a computer, plug in the device and click *Installera*.

Contents: `index.html` (page), `manifest.json` (ESP Web Tools manifest), `firmware/harmonica-key.bin` (merged image, flashed at offset 0).
`build.sh` rebuilds the firmware from the (separate, local) project source.
